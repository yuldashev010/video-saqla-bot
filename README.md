# 🎬 Video Saqla Bot

YouTube, Instagram va TikTok video havolalarini
yuklab olishga yordam beruvchi Telegram bot.

## Imkoniyatlar

- YouTube havolalari
- Instagram havolalari
- TikTok havolalari
- /start va /help buyruqlari
- Vaqtinchalik fayllarni avtomatik o‘chirish

## O‘rnatish

Kerakli kutubxonalarni o‘rnating:

pip install -r requirements.txt

## Token sozlamasi

Environment variable nomi:

TELEGRAM_BOT_TOKEN

Value qismiga BotFather bergan tokenni kiriting.

## Ishga tushirish

python bot.py

## Eslatma

Ayrim videolar platforma cheklovlari,
login talabi yoki boshqa sabablarga ko‘ra
yuklanmasligi mumkin.

Bot tokenini hech kimga bermang.
